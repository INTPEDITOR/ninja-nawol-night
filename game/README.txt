수련해라! 닌자 나월!
Windows 앱: 압축을 전부 푼 뒤 닌자나월.exe 실행.
웹 미리보기: 이 폴더의 index.html 실행.

게임 시작 → 스테이지 선택 → 수련.
150개 스테이지마다 서로 다른 사물이 등장합니다.
클리어 전에는 이름 ???와 검은 실루엣만 표시하며 다음 단계가 순차 해금됩니다.
원하는 위치를 클릭하면 왼쪽에서 여성 닌자의 팔이 뻗었다가 돌아옵니다.
주먹의 이동 범위는 브로치가 떨어지는 지점까지입니다.
브로치는 위에서 떨어지며 바닥 없이 화면 아래로 사라집니다.
R: 다시 떨어뜨리기 / Space: 펀치 / Esc: 스테이지 선택.
초승달의 뾰족한 두 끝만 꽂힙니다. 둥근 면이나 잘못된 속도·각도의 충돌은 튕깁니다.
사물 위에 안정적으로 얹혀 있어도 성공합니다.
후반에는 관통 조건, 표적 이동, 바람과 장애물로 난이도가 올라갑니다.
성공 화면에서는 사물 전체와 박힌 브로치를 조명 아래 전시합니다.
화면을 누르면 다음 단계로 이동하며 음악은 즉시 멈춥니다.
옵션: 해상도, 최대화, 소리 켜기/끄기. 게임 화면은 항상 16:9입니다.
진행과 옵션은 자동 저장됩니다.

최근 수정: 옵션 창 이미지 배경·명조 글꼴·버튼 겹침 수정. 메인화면에 자체 제작한 닌자풍 연주 BGM을 추가했습니다. 메인 BGM은 게임 시작 시 멈추고, 소리 옵션으로 함께 제어됩니다. 낙하 궤적과 브로치 주변 원은 표시하지 않습니다. 놓친 뒤에도 게임은 계속 동작하며, 다시 떨어뜨리기는 R키로만 가능합니다.
